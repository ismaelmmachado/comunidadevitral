# AGENTS.md — Comunidade Vitral

## Stack
- Site estático moderno
- Sem dependência de Wix
- Deploy em GitHub Pages

## Estrutura do site
Seções confirmadas:
- Home
- Sobre
- Mensagens
- Encontros
- Voluntariado
- Como Contribuir
- Visite-nos

## Regras do projeto
- Preservar conteúdo e tom acolhedor/inclusivo
- Não perder dados institucionais: nome, endereço, telefone, e-mail
- Mobile-first
- SEO básico obrigatório

## Comandos
- Build: npm run build
- Preview: npm run preview
- Typecheck: npm run typecheck

## Branch
- Trabalho padrão: `homologacao`
- Produção: `main`
- Merge em `main` só quando usuário pedir deploy
